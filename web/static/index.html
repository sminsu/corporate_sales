    업무 질문 예시

    기업영업지원 에이전트 질의

    기업영업에 관련된 질의만 진행합니다. 카드 관련 문의나 개인영업 및 개인정보에 관한 질의에는 답변할 수 없습니다.

    • 한도소진율이 90% 이상인 기업 리스트 100개만 만들어줘.
    • KB카드 기업카드 보유회원 중에 2026년 7월 기준으로 6개월 무실적인 기업 회원 명단을 알려줘.

    가맹점 · 프랜차이즈 관련 질의

    가맹점이나 프랜차이즈 관련 질의에 대해 답변합니다.

    • 2026년 4월 꾸석지(가맹점이름)의 대손비용률 분석해줘.
    • 빽다방(가맹점이름) 가맹점주 중에 2026년 5월 기준으로 폐업처리된 건 몇 개야?

    답변 범위를 벗어난 질문

    위 두 가지에 해당하지 않는 질문에는 “이 에이전트가 답변할 수 있는 범위가 아닙니다”라고 답하고, 대신 어떤 질문을 하면 되는지 예시를 안내합니다. 개인영업 · 개인고객과 개인정보, 카드 상품 안내나 분실 · 재발급 같은 고객센터 문의, 그 밖의 일반 대화는 다루지 않습니다.

    좋은 질문을 하는 방법

    안내사항

    상세 데이터와 SQL은 오른쪽 상세 패널에서

    답변의 근거가 된 조회 데이터와 실행 SQL은 화면 오른쪽 위 상세 버튼을 누르면 볼 수 있습니다. 데이터 탭에서 조회된 표를, SQL 탭에서 실제로 실행된 쿼리문을 확인하세요.

    전체 데이터는 보고서 내보내기로 받으세요

    화면의 데이터 탭은 최대 100건까지만 미리보기로 보여줍니다.

    전체 데이터가 필요하면 왼쪽 아래 데이터 도구 → 보고서 내보내기에서 Excel 또는 TXT를 누르세요. 미리보기 100건이 아니라 조회된 전체 행을 파일로 내려받습니다. (Word 보고서는 표를 200건까지만 담으므로 전체 데이터는 Excel · TXT를 이용해 주세요.)
